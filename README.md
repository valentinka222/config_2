# Визуализатор графа зависимостей пакетов

Инструмент командной строки для анализа и визуализации зависимостей пакетов
Ubuntu (apt). Текущий этап: чтение и проверка конфигурации из XML-файла.

## Функции и настройки

Приложение читает XML-файл (путь передаётся первым аргументом), проверяет
значения всех параметров и выводит их в формате «ключ = значение». При ошибке
выводится сообщение `Ошибка конфигурации: ...`.

| Параметр | Описание | Допустимые значения |
|---|---|---|
| `package` | Имя пакета | строчные латинские буквы, цифры, `. + -` (в тестовом режиме: большие латинские буквы) |
| `version` | Версия пакета | вид `[эпоха:]версия[-ревизия]`, начинается с цифры |
| `repository` | URL репозитория или путь к тестовому файлу | `http://`/`https://` URL (в тестовом режиме: путь к существующему файлу) |
| `test-mode` | Режим тестового репозитория | `true` / `false` |
| `output-file` | Имя файла с изображением графа | имя с расширением `.png` |
| `ascii-tree` | Вывод ASCII-дерева | `true` / `false` |
| `max-depth` | Максимальная глубина анализа | целое число не меньше 1 |
| `filter` | Подстрока для фильтрации пакетов | строка без пробелов, может быть пустой |

## Сборка и тесты

Нужен JDK 21. Запуск (собирает проект в `out` и запускает):

```bash
run.bat tests\configs\ok.xml        # Windows
./run.sh tests/configs/ok.xml       # Linux / macOS
```

Тесты (Windows): `tests\test_ok.bat` (корректные конфиги) и
`tests\test_errors.bat` (ошибки по каждому параметру).

## Примеры использования

```
> run.bat tests\configs\ok.xml
package = bash
version = 5.1-6ubuntu1
repository = http://archive.ubuntu.com/ubuntu
test-mode = false
output-file = graph.png
ascii-tree = true
max-depth = 3
filter = lib

> run.bat tests\configs\error-depth-text.xml
Ошибка конфигурации: Параметр <max-depth> должен быть целым числом, а не 'abc'

> run.bat
Ошибка конфигурации: Не указан путь к конфигурационному файлу
```
